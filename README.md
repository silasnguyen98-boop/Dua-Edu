# Dua-Edu

## Supabase setup

This project uses Supabase through `@supabase/supabase-js`.

Create `.env.local` with:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://nnkwzjkbzwehxryulshv.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
```

Then run:

```bash
npm install
npm run dev
```
